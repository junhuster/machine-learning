# LLM 预训练与微调模型推理测试

> 测试环境：单张 T4 GPU（16GB 显存）  
> 数据集：出门问问序列猴子数据集（预训练约 30GB，微调约 5GB）

## 综合评估

| 模型                 | 对话能力  | 事实准确性 | 推理速度          | 综合评价                                       |
| ------------------ | ----- | ----- | ------------- | ------------------------------------------ |
| GPT-2 (72M)        | ❌ 无   | ❌ 无   | 快 (0.4-0.6s)  | 仅预训练，无对话能力，输出为续写乱码                         |
| LLaMA2 (219M)      | ✅ 有   | ⚠️ 一般 | 中 (0.4-4.6s)  | 有基础对话和事实能力，简单问题可正确回答                       |
| DeepSeek-V3 (408M) | ⚠️ 有限 | ❌ 差   | 快 (0.2-0.7s)  | 仅简单问题正确，复杂问题答非所问                           |
| LLaMA4 (242M)      | ✅ 有   | ⚠️ 一般 | 最快 (0.1-0.9s) | 对话流畅，简单问题正确，复杂问题有偏差但能识别核心实体（如正确识别宋徽宗为北宋皇帝） |

### 关键发现

1. **GPT-2（仅预训练）完全无对话能力** — 输出为续写模式，无法理解指令，回答均为乱码或重复问题
2. **SFT 显著提升对话能力** — LLaMA2/4 和 DeepSeek-V3 经过 SFT 后具备对话能力，能正确回答简单事实问题
3. **参数量不等于效果** — DeepSeek-V3（408M）效果反而不如 LLaMA4（242M），说明训练策略和数据质量更重要
4. **DeepSeek-V3 效果不佳的可能原因** — DeepSeek-V3 词表较大，30GB 预训练数据相对不足以充分训练所有 token，导致部分 token 训练不充分，影响了模型整体表现
5. **复杂问题普遍困难** — 所有模型在历史人物关系、地名等复杂问题上都有不同程度的错误，受限于模型规模
6. **LLaMA4 综合表现最优** — 对话流畅、速度快、简单问题准确率高，复杂问题上虽有不准确但能识别核心实体（如正确识别宋徽宗为北宋皇帝，应天门方向判断较接近），适合单卡资源受限场景
